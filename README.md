# 🎨 Art-Space

**Art-Space** is a simple Android app I built as part of my Android Studio training. It’s a basic version of an art gallery app that lets users browse through a small collection of artwork.

## 🌟 Features

- Browse **4 artworks** with their corresponding **artist names**
- Navigate using **Next** and **Previous** buttons
- Minimal and clean UI
- No fancy animations (keeping it lightweight and simple for now)

## 📱 How it Works

- Tap **"Next"** to view the next artwork  
- Tap **"Previous"** to go back to the previous artwork  
- The app cycles through a fixed collection of 4 images

## 🚧 Current Status

This is **version 1** of the project — a foundational step in my Android development journey.  
Future improvements may include smoother transitions, expanded image sets, or even a database backend.
